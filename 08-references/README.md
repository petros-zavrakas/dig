# References — designs the owner likes

One folder per theme. For **every** image, add a line to the table below that says
**what to take from it**: the density, the colours, the way the menu collapses, and so on.
Equally important is what **not** to take, so the designer does not copy a whole page
when only one detail is meant.

| File | Take from it | Do not take |
|---|---|---|
| `navigation/example.png` | e.g. the slim icon sidebar that expands on hover | e.g. the colours |
